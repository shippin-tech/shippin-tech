# keys

Every place a person pastes a key, or is handed one, shows `KeyNotice` with the variant for
that key, and `/keys` lists them all. The wording says plainly that this field is where the key
belongs, where the key comes from, how it is kept, where it goes and what proves it.

Each statement is true of the code and covered by a test. Change the wording in `keys.ts`
only together with the code and the test it describes. `KEYS.md` at the top of the
repository says the same for operators and AI agents.

Kernel: `ui/src/lib/ai-runtime/admin/kernel/instruction.md`.
