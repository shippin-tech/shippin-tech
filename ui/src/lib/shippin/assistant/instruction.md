# assistant

The assistant explains how the product works. It answers from `resources/product/api.json` and `resources/product/lessons.json`, filtered by the person's role. It has no tools: it cannot see anyone's mail or change anything, and it must stay that way. Conversations live only in the open page.

AI settings at `/shippin/admin/ai` choose the service: any OpenAI-compatible address, including a self-hosted Ollama, or Anthropic's API. It is off until an administrator sets it. The server side is `crates/common/src/shippin/ai.rs` and `crates/http/src/shippin/assistant.rs` (`/api/assistant`, `/api/ai`). `resources/product/lessons.json` is generated by `ui/scripts/check-mcpl.mjs --write`.

Kernel: `ui/src/lib/ai-runtime/admin/kernel/instruction.md`.
